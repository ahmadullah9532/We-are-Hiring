# We-are-Hiring | د دندو پاڼه

## د پاڼې موخه

دا پاڼه د دندو د اعلانونو او د غوښتنلیک د معلوماتو لپاره ده. د هرې دندې شرایط، وروستۍ نېټه او د غوښتنلیک لاره به د هماغې دندې په اعلان کې خپرېږي.

## دندې

### Junior Web Developer — د وېب پراختیا لومړنۍ کچې دنده

| معلومات | وضعیت |
| --- | --- |
| د غوښتنلیکونو حالت | لا نه دی اعلان شوی |
| د کار ځای او دندې ډول | لا نه دي اعلان شوي |
| مسؤلیتونه او د وړتیا شرایط | لا نه دي اعلان شوي |
| د غوښتنلیک وروستۍ نېټه | لا نه ده اعلان شوې |

## د غوښتنلیک سپارلو طریقه

د غوښتنلیک رسمي لاره لا نه ده اعلان شوې. کله چې د دندې بشپړ اعلان خپور شي، د وړتیا شرایط او وروستۍ نېټه وګورئ او خپل غوښتنلیک په اعلان کې له ښودل شوې لارې وسپارئ.

## اړیکه

د استخدام لپاره رسمي برېښنالیک، د اړیکې شمېره یا فورمه لا نه ده خپره شوې. د اړیکې معلومات به د دندې په بشپړ اعلان کې درج شي.
